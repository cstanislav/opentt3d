# Moving-aircraft clearance and complete effect-source references

This preview corrects a boarding-pier support that intersected larger Toyland aircraft
during actual smoothed turns. It also binds Toyland forest slots to source-identical
cotton-candy artwork and adds read-only tools for the remaining clearance/effect work.

## Play

The [verified `.26` desktop release](https://github.com/cstanislav/opentt3d/releases/tag/opentt3d-dev-20260927.26)
is available for Windows, macOS and Linux. All eight exact-commit packaging jobs pass.
Required graphics are bundled; see the
[installation guide](https://github.com/cstanislav/opentt3d/blob/main/opentt3d/PLAYING.md).

## Changes

- Recessed one NW boarding-pier support beneath its existing beam. Aircraft dimensions,
  original movement, the other supports and the beam remain intact.
- Added sixteen explicit Toyland forest body/ground aliases after proving that their
  original pixels, palettes, sizes and offsets match the existing cotton models.
- Added read-only emitted-pose traces and a fractional-turn voxel-intersection audit.
- Catalogued all 81 original effect sources used by twelve effect types. Eighty are
  presentable; the remaining bubble image is an unpresented transition. Source exports
  preserve fixed anchors and consume no simulation RNG.
