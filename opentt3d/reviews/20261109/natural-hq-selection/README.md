# Natural company-score HQ selection — stage4

The title company has actual performance score **870** (retained economy history).
A normal original HQ build command was executed at flat tile67,1; no score or
stage was forced. The economy then selected **HQ stage4** through
`UpdateCompanyHQ`, and the console read-back reported:

`HQ company 0 tile 67,1 stage 4 score 870`

The actual save, console acknowledgement, build run and a Vulkan screenshot at
the HQ are retained. The model is the authored larger-HQ family. Earlier stages
are still governed by the original thresholds; this review establishes natural
high-score stage selection, not a forced-stage shortcut.
