# River-relief forced-world review

The eight retained river-relief volumes were rendered in an actual Vulkan saved
world at a slope-6 river tile. The run retained the real `smoke-state.sav`, nine
ordered console acknowledgements, the exact synchronous save-success line and a
1280x960 world screenshot. The forced relief logs identify slope 6/climate 0 at
tiles 87..89,15.

## Limit

The relief draw was forced by a temporary `OPENTT3D_FORCE_RIVER_RELIEF` hook that
is not part of the committed runtime. The default/custom river feature selector
did not independently qualify this fixture, so natural custom river-source
selection, zero-feature absence, phases and all climate/slope families remain
open runtime gates. The world proves model placement/rendering, not natural
feature selection.

The earlier isolated 5/10 reviews remain in git history. The forced-world review
accepts the eight models and192 conditional sloped-bank instances at9/10 for
visible structure, placement and source ownership; the natural feature gates
remain separate.
