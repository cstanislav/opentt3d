# Lock and river 3D coverage recovery

This review binds two recovered authored families without promoting them to 9/10:

- 48 original lock-wall volumes, covering all three parts, four directions, two
  faces, two elevations and four climates (192 owner states).
- 8 river-relief volumes, covering four original slope bits and four climates
  (16 owner states).

The source is the previously retained, source-derived lock/river study set. No
geometry was inferred from pixels or sorting extents. The catalogue now contains
1971 models. The 192 lock owner rows and 192 conditional sloped-bank rows are
explicit `authored-voxel-instance` entries at 5/10; complete-family binding is not
an individual visual approval.

## Native evidence

Both Vulkan and OpenGL ran the original lock fixture in the background with
`--record-console` and `--synchronous-save`. Each retained an actual
`smoke-state.sav`, ten ordered console acknowledgements and the exact
`Map successfully saved to 'smoke-state.sav'.` line. The live log records the
voxel lock walls replacing the original wall owners with independent original
water ground.

The river gallery exports all eight relief models (80 reference images) and
retains an acknowledged synchronous save. The fixture has no live custom
`CF_RIVER_SLOPE` selection, so this proves model loading, not active world
substitution.
