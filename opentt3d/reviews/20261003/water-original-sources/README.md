The unmodified, independently downloaded exact-tag `.42` Mac app exports all
48 default rear/front lock sprites and four default water slopes in each climate.
Eight quiet Vulkan/OpenGL controls pass atlas/picking and acknowledged synchronous
saves. All208 paired source images retain exact registration metadata and PAM bytes.

`tools/assets/original_water.py` inventories the three parts/four directions/two
default elevation selections, independently owned animated water, rear/front sequence
anchors and sorting extents. It also retains the sixty unresolved custom river-bank
offsets and intentional absence when the original river feature supplies no bank.
Sorting extents are not artwork dimensions; source IDs are not live Classic/NewGRF
selection. No lock/river binding, model, geometry, state, clearance or quality is
approved by these source exports. Simulation, commands, terrain, callbacks and RNG
are unchanged. Live resolved selection must be observed before authoring bindings.

The working-candidate asset tests pass235; a separate committed-artwork test tree
excludes all experimental larger-HQ/compiler/tests. Portable receipts, per-climate
metadata and original PAMs are bound by `evidence-sha256.json`. These audit times
are not a stopping clock or completion of the full catalogue-wide objective.
