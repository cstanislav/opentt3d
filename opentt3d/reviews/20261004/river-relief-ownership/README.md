and consistent, with every model at least 8/10**. This increment does not meet it.
Canonical artwork/bindings and recommended immutable `.42` are unchanged. Nothing
here approves a model, a supported instance, ship clearance, animation completeness
or sustained performance. The following are diagnostic controls, not release assets.

## Safe diagnostic interception and separate geometry

The `river_relief` schema allows only original slope bits **3/6/9/12** and explicit
climates **0…3**. No flat decoration is fabricated. Interception requires the
actual Classic source file, original flat-first `flags == 1`, unchanged requested/
resolved offsets, no crop, original offsets/anchor, exact five-component source
bytes, and all four relief plus water owners for that climate. Changed, missing,
alternate/custom and redirected sources keep their originals. Dynamic IDs are
never hard-coded. Both original draw selectors/callbacks run in their original
order. No game commands, simulation, saves, ratings, scripts or RNG are changed.

Each original volume gains only the extra doubled-terrain support plane: columns
lift, object height does not scale, XY/paint/air ownership remain exact, and support
joins are split. Independent original-layer water retains animated remap entries.
Supported LODs at factors **1/2/4/8/16**, copied-scene leases, exact restoration and
stable mesh identities retain the existing CPU/GPU budget policies.

Three retained forty-world matrices use isolated `canonical`, `complete`,
`missing-owner`, `missing-water`, `changed-source` catalogues. Each matrix includes
all climates, supplemental tropical seed161803 and actual OpenGFX fallback. Saves
are paused public fixtures, commands acknowledged, `gui.threaded_saves=false`,
original headers/files checked and `Map successfully saved` retained. Every native
run is hidden/nonactivating (`--background`) and uses `--blitter 40bpp-anim`.

The latest matrix retains sixteen emitted climate/slope combinations at observed
