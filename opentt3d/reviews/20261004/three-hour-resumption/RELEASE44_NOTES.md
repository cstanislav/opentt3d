# OpenTT3D development .44 — Windows checkout recovery

**Development draft; publication is withheld until all original packaging and
independent-download/native checks pass.**

This preserves the .43 shore/HQ/zero-heading work and enables Git long paths
before Windows checkout. The first .43 build passed source, macOS ARM64,
macOS x86_64 and Linux, but all three Windows jobs failed before compilation:
retained original evidence paths exceeded Windows MAX_PATH. Those failures and
the immutable .43 tag/draft are preserved, not hidden by removing evidence or
skipping Windows. Two checkout regression tests guard the repair. The .44
packaging run is a fresh recovery attempt, not an already accepted release.

Twenty new manually authored shore-bank studies were individually screened at
4–5/10. All 120 bank studies and all 84 larger-HQ proposals remain unbound; no
quality approval or accepted bank/larger-HQ runtime coverage is claimed.
Scoped zero-heading GL/Vulkan identity parity preserves 2,498 complete
same-backend images and ten save pairs, with unchanged nonzero rotations.
Actual terrain-query/source evidence is retained, including all failed controls.

The every-runtime-asset-3D / every-model-8/10 / sustained-60fps objective is
unfinished. Source fidelity, strict whole-world backend equality, conditional
states, support/LOD/picking/ship clearances, memory and platform/input/replay/
network gates remain open. The fresh bounded saved-size1 controls have near-60
average FPS but 421 Vulkan / 181 OpenGL intervals over20ms and approximately3GiB
process peaks; sustained60fps is not accepted. Windows ARM64 execution and
Windows GPU/foreground input remain unverified.

[Immutable .42](https://github.com/cstanislav/opentt3d/releases/tag/opentt3d-dev-20261003.42)
remains recommended. No older tag, notes, package or recommendation is replaced.
