# Locks in saved 3D worlds — diagnostic only

The 48 provisional lock studies now have **separate diagnostic world bindings**,
not released artwork. Original callbacks still select and draw both wall sources.
Only a complete Classic family with valid original provenance, order, registration,
extents and both matching selections replaces those draws. Any missing owner or
alternate/custom source retains the entire original family. Independent original
water is neither hidden nor bundled into a wall.

Middle-wall columns gain only the additional doubled-terrain support. Objects are
not height-scaled; source cells, six-face paint, horizontal anchors, openings and
separate upper/lower ownership remain unchanged. Support joins split greedy faces
before the shear. Factors 2/4/8/16 preserve occupancy and scene leases; retirement
reconstructs exact supported vertex words under the existing soft cache budgets.
